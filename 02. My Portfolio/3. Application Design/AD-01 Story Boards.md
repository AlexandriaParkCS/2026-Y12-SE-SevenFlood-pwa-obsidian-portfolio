The storyboard demonstrates the user journey through the Loyal Cafe application, showing how customers interact with the loyalty system from the first screen to the dashboard.

The first screen is the Loyal Cafe home page. This page displays the Loyal Cafe logo and provides two main options: Login and Sign Up. New users select the Sign Up button to create an account, while existing users can log in to access their loyalty information. The simple layout helps users quickly understand what action to take.

The second screen is the Sign-Up page. Here, new users enter their username, email address, and password to register for the Loyal Cafe loyalty program. The password requirements (minimum 8 characters, including upper and lower case letters) help ensure account security. Once the form is completed, the user presses the Sign Up button to create their account.

After successfully signing up, the user is taken to the dashboard screen. The dashboard acts as the main hub of the application and displays the user’s account. From this screen, users can access their loyalty card, claim rewards, and view their transaction history. This allows customers to easily track their progress toward free coffee and manage their loyalty rewards.

Overall, the storyboard shows a simple and intuitive flow, guiding users from account creation to accessing their loyalty features within the Loyal Cafe PWA.
