# PP-08 Budget

This section describes the estimated costs associated with developing and operating Loyal Cafe. As a student-led school project, the majority of tools and services used are free or available at no cost through education licences.

## Cost Breakdown

|   |   |   |
|---|---|---|
|**Item**|**Estimated Cost**|**Notes**|
|Development Hardware|$0|Existing school/personal laptop|
|Python 3 + Flask|$0|Free, open source|
|SQLite|$0|Bundled with Python, no server required|
|Visual Studio Code|$0|Free editor|
|GitHub (version control)|$0|Free for students via GitHub Education|
|Bootstrap 5 (CSS framework)|$0|Free, open source CDN or local file|
|Hosting (development)|$0|Runs locally on localhost:5000|
|Hosting (optional production)|$0–$10/month|e.g. Render free tier or PythonAnywhere hobby plan|
|Domain Name (optional)|$15–$20/year|Only required for public deployment|
|SSL Certificate|$0|Let's Encrypt provides free TLS certificates|
|Labour|$0|Student-led development|
|Training / Research|$0|Flask documentation, YouTube, online tutorials|

## Total Estimated Cost

|   |   |
|---|---|
|**Scenario**|**Estimated Total Cost**|
|Development only (local)|$0|
|With optional production hosting (12 months)|$0–$120|
|With domain name + hosting (12 months)|$15–$140|

The project is designed to be deployable at zero cost using free-tier hosting services. Any costs beyond $0 are entirely optional and only arise if the application is deployed to a public server with a custom domain name.
