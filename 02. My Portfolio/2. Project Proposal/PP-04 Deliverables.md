# Project Deliverables

The project is a Progressive Web App called **Loyal Cafe Rewards**. The purpose of the application is to replace a paper coffee loyalty card with a digital Flask and SQLite system that customers can access on their phone.

## Portfolio Deliverables

| Deliverable | Evidence Included | Status |
| --- | --- | --- |
| Problem definition | Explanation of issues with physical loyalty cards, including lost cards, waste, fraud risk and lack of customer tracking. | Completed |
| Proposed solution | Description of how a PWA can improve customer convenience, business efficiency and reward tracking. | Completed |
| Design sketches | Storyboard showing the home screen, sign-up screen and dashboard journey. | In progress |
| Database planning | Entity relationship diagram plan, data dictionary and table structure for users, loyalty cards, rewards and transactions. | In progress |
| Implementation evidence | GitHub repository link, commit log evidence and notes about implemented Flask, SQLite, security and PWA features. | In progress |
| Testing evidence | Test cases and test report for sign-up, login, staff/admin points, rewards, history, role protection and PWA behaviour. | In progress |
| Reflections | Journal entries explaining challenges, decisions, solutions and future improvements. | In progress |

## Application Deliverables

The application includes or is designed to include:

- A home page with clear Login and Sign Up options.
- A secure sign-up form that collects username, email and password.
- A login page for returning customers.
- A dashboard that shows the customer loyalty points progress.
- Staff/admin pages for searching customers and adding purchase points.
- A rewards page for claiming rewards when enough points are available.
- A transaction history so users can see previous purchases and rewards.
- Security features such as password hashing, CSRF protection and role checks.
- PWA features such as responsive design, installability, service worker caching and an offline page.

## Success Criteria

The project will be successful if the portfolio clearly proves each stage of development and the final application shows how a secure digital loyalty system improves on the original paper card system.
