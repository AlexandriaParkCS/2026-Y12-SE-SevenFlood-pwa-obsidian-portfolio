## Technology Resources

The following tools and technologies are used in the development and operation of Loyal Cafe:

|                    |                                                             |                           |
| ------------------ | ----------------------------------------------------------- | ------------------------- |
| **Resource**       | **Purpose**                                                 | **Availability**          |
| Python 3 + Flask   | Backend web framework and routing                           | Free, open source         |
| SQLite 3           | Relational database for users, cafes, rewards, transactions | Free, bundled with Python |
| Flask-WTF          | CSRF protection on all POST forms                           | Free, open source         |
| Werkzeug           | Password hashing (bcrypt)                                   | Free, bundled with Flask  |
| Visual Studio Code | Primary code editor                                         | Free                      |
| GitHub             | Version control and issue tracking                          | Free for students         |
| Bootstrap 5        | Responsive CSS framework for templates                      | Free, open source         |
| Chrome DevTools    | PWA testing, Lighthouse audits                              | Free, bundled with Chrome |
