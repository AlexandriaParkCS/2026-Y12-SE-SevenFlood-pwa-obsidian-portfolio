# Project Journal

**Date:** 10 Mar 2026  
**Project:** Loyal Cafe Rewards PWA  
**Module:** Flask application setup

## What I Did

- Worked on the Flask application structure.
- Used templates for the main pages such as index, signup, login, dashboard and layout.
- Set up static folders for CSS, JavaScript, images, icons and PWA files.

## Why I Did It

The application needed a proper structure so pages, styling and scripts were organised. This makes the project easier to expand as more features are added.

## Challenges

The main challenge was understanding how Flask connects routes, templates and static files. If the paths are wrong, pages or assets do not load correctly.

## How I Solved Them

I kept the app organised inside the `src` folder and used Flask routes to render the correct templates. I also kept shared layout parts in template partials such as the menu and footer.

## Next Steps

- Build the sign-up and login routes.
- Connect forms to the database.
- Add validation so users cannot submit weak or incorrect account details.

## Reflection

This stage helped turn the project from an idea into an actual application. The folder structure gave me a base to keep building from.
