# Project Journal

**Date:** 2 Apr 2026  
**Project:** Loyal Cafe Rewards PWA  
**Module:** Dashboard and reward progress

## What I Did

- Built the customer dashboard page.
- Displayed the logged-in user's current points.
- Added a reward progress bar showing progress toward 100 points.
- Added quick actions for rewards, history and reminders.

## Why I Did It

The dashboard is the main page customers use after logging in. It needs to quickly answer the main question: how many points do I have and how close am I to a reward?

## Challenges

The challenge was making the points display easy to understand. A raw number is not enough, because users also need to know how close they are to the next reward.

## How I Solved Them

I created reward progress logic that calculates the current progress, remaining points and percentage. This makes the dashboard more useful than just showing a points total.

## Next Steps

- Add reward redemption.
- Add transaction history.
- Improve the mobile layout so the dashboard works well on phones.

## Reflection

The dashboard became one of the most important screens in the app. It helped connect the database work to something the user can actually see and understand.
